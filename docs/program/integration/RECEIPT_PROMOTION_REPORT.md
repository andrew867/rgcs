## Fallback policy attestation

Adapters prefer the bundled Codex cores; the reference demos execute
only if a core import fails, in which case `guard_fallback` caps the
status at YELLOW and stamps `REFERENCE FALLBACK IN USE` into warnings.
With the integrated wheel the cores are always present, so no shipped
receipt was generated by a fallback (verify: every shipped receipt's
warnings contain `backend=rgcs_lab.<core>`; none contains the fallback
marker).
