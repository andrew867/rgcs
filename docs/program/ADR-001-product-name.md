# ADR-001 — Product name

**Status:** accepted 2026-07-26 (Claude, authority lane)

**Decision:** the unified public application is named **RGCS Recursive
Infrastructure Lab**, per the Master Program Prompt's provisional
designation. The name is exposed as
`rgcs_lab.PRODUCT_NAME` and consumed by the hub registry — UI surfaces
must read it from there, not restate it.

**Rename rule:** renaming requires a superseding ADR in this
directory, recorded before any UI or docs change. No agent may rename
in code or copy alone.

**Context:** the thesis is to win attention with working, falsifiable
systems, not a theory-of-everything banner; the name deliberately says
"infrastructure lab", not any physics outcome.
