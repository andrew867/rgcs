# Orion's Arm Convergence Ledger

## Claim boundary

Orion's Arm is a **collective hard-science-fiction worldbuilding project**. It
self-describes as a speculative future, not a factual disclosure archive.

RGCS uses it as:

```
HARD_SF_DESIGN_CONVERGENCE
PUBLIC_LORE_ANALOGUE
SCIENCE_FICTION_PRIOR_ART
```

RGCS does **not** use it as:

```
FACTUAL_DISCLOSURE
PHYSICAL_VALIDATION
AUTHORITY_ABOVE_TESTS
```

Nothing in the V1 codec, projector, or test suite depends on any OA material. If every
OA reference were deleted, no verdict and no blocker would change. That is the test of
whether a source is being used as a prior or as evidence.

---

## Why a hard-SF corpus is useful at all

A worldbuilding project that has spent decades separating propulsion mechanisms into
consistent taxonomies is a good **source of distinctions** — it suggests which
questions are separable and what to test. It is worthless as confirmation, because it
was written to be internally consistent, not to be true.

The failure mode this ledger exists to prevent: finding that OA describes a 30 km
field envelope, noticing RGCS has a 15 km residual, and treating the match as support.
It is not. Two numbers agreeing tells you they agree.

## Release language

**Use:**

> OA independently organizes many of the same propulsion, coordinate, and material
> motifs into hard-SF taxonomies. This helps RGCS separate mechanisms and generate
> tests.

**Do not use:**

```
OA proves RGCS.
OA is disclosure.
OA validates The L's.
```

The same rule applies to every other lore or provenance source in this programme —
The L's, JH, crop-circle material, Siloen, Falcon Lake. They may motivate a test.
They may never stand in for one.
