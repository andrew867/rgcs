# Advanced Scientific Workbench

Advanced Mode is the existing research workbench, unchanged: source library,
specimen editor, model registry, pulse designer, experiment builder, comparison
views, results browser, evidence ledger, reports, and export bundles.

## Opening it

From the Design Studio home, choose **Open Advanced Scientific Workbench**, or
press `Ctrl+K` and type the panel name. Design Studio panels and Advanced Mode
panels share the same workspace, jobs dock, and inspector.

## Relationship to Design Studio

Design Studio is a guided layer over the same services. Anything you create in
Design Studio (specimens, designs, receipts) is visible to Advanced Mode tools,
and the claim-classification badges are the same in both modes.
