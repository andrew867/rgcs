# Binaural Companion

## Core formula

```text
beat  = right - left
left  = carrier - beat/2
right = carrier + beat/2
```

Patent-style example (PAT-US5213562A): left 100 Hz, right 104 Hz →
4 Hz binaural beat. In the studio's convention that pair is carrier
102 Hz with beat 4 Hz.

## Session shapes

**Standard**: fade in → settling → target beat ramp → hold → return →
fade out → notes.

**Gateway-style (independent)**: orientation → relaxation → breathing
cue → intention cue → target ramp → focus-state hold → free
exploration → return → fade out. Built from public methodology
(GOV-GATEWAY-1983); no official tape structure or narration is
reproduced.

**Hemi-Sync-inspired independent composite**: binaural carrier pairs +
pink noise + surf/ambient bed + optional music bed and voice cues with
slow amplitude/pan automation. Independent architecture only — no
official recordings, names, or branding.

## Practical use

Stereo headphones for binaural sessions. Comfortable volume. Start
with 10–20 minutes. Save notes after each run. Results vary.
