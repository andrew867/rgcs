# Frequency Keys

The Frequency Key Library exposes the project's frequency keys as selectable,
sourced, testable records.

## Fields

Each key records: value (Hz), label, family, source status, source IDs,
mathematical relations, audio role, modulation role, hardware role, and its
null/downgrade criteria.

## Source status

Keys are classified as **sourced** (reproduced from source material — preserved,
not endorsed), **mathematical relation** (e.g. 925 = 37 × 25), **project
candidate**, or **custom** (user-entered, labelled as such). 4096 Hz remains
the explicit base pulse in hardware workflows; note the published null result —
4096 Hz is not the electromagnetic surface-wave carrier at annulus scale.

## Using keys

Selecting a key in the Coil / Pulse Designer or Annular Ring Designer updates
the sideband table: carrier ± key. For example, 4096 ± 925 → 3171 and 5021 Hz.

## Claim boundary

Frequency keys are recorded as sourced values, mathematical relations, or
project candidates. Audio or modulation recipes are test recipes, not proof of
outcome.
