# R10.15 Negative Results

Published beside the positive outputs, as the evidence policy requires.

## N1: 4096 Hz is not the electromagnetic surface-wave carrier

- class: NULL
- ordinary explanation: the annulus is 1e-5 wavelengths around at 4096 Hz; it is an electrically tiny quasi-static object there. 4096 Hz is a switching and phase reference, which is what the source record describes.
- what would change it: a structure with a slow-wave factor above 1e5, i.e. a resonator ~5 orders larger or a genuinely different physical mechanism

## N2: Space-time nonreciprocity does not engage at 16 Hz modulation

- class: NULL
- ordinary explanation: sidebands sit ~6 orders inside one resonance linewidth; the modulation is adiabatic with respect to the mode
- what would change it: Q above 3.6e7, or modulation raised into the MHz range comparable with the linewidth

## N3: Constructed harmonic field model did not converge and was withdrawn

- class: NULL
- ordinary explanation: a modelling error, found by an independent convergence dimension and published rather than hidden
- what would change it: nothing; the model is withdrawn

## N4: Isolated distribution has zero self-force; no configuration produces unbalanced momentum

- class: NULL
- ordinary explanation: lateral force is an ordinary m=1 asymmetry force balanced by the support reaction; momentum closes
- what would change it: a momentum ledger that fails to close once every body is included

## N5: Exactly diametric omitted-cell pair is impossible on an odd cell count

- class: NULL
- ordinary explanation: arithmetic: no pair of 35 equally spaced indices differs by exactly pi
- what would change it: an even cell count
